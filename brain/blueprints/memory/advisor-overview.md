# Advisor memory

This blueprint is the advisor's working memory. Briefings are filed here after
a search for an existing entry. Prefer one concept per entry, a short unique
title, and enough context that a later `ask_question` can use it without the
original dump.

| Category | Put here |
|---|---|
| Facts | Stable true things |
| Context | What is happening now |
| Preferences | Values, constraints, how they work |
| Goals | Desired outcomes |
| Decisions | Commitments and why |
| Insights | Distilled reusable observations |
| Sources | Notes from books and other valued material |
| Open questions | Unresolved questions |

Do not file transferable practices here — those belong in a skill.
